# 91906-91907: Takeaway Ordering System

## Running

1. Install [uv](https://github.com/astral-sh/uv) OR install pillow via `pip install pillow>=11.0.0` and Python 3.9.25
2. Open a terminal and change directory to where this program is located
3. If you are using uv, run `uv run main.py`, otherwise run `python main.py` (you may need to specify where your installation of Python 3.9.25 is explicitly)
